# ADR-H0-0004 — 登録済み作業中のテスト変更をguardで停止する

H0はtest ID集合とsourceを照合するが、旧guardのprefixにはtests/が含まれなかった。
そのためallowed_pathsにtests/があるsessionでは、同じtest IDを保ってassertionを弱めた場合、
実装者の手続遵守に依存していた（同OS userを敵対者から防ぐ保証ではないこととは別の抜け）。

テスト先行で、許可path内のassertion書換えでもGUARD_CHANGEDとなる負例が失敗することを確認。
guard_digestへtests/を追加した。テストを変更する正当な作業は別candidateとして行い、
変更後のcase inventoryをreviewし、fresh sessionから実行する。実装sourceだけの変更は許す。
source/guard digestは変わるため以前のH0 receiptは再利用せず再実行する。

これは同一ユーザーによるguard自体の改造を防ぐOS sandboxではない。既存の保証境界を維持する。
今回のreviewは同一作者のself-review。独立reviewはNOT_RUN。
