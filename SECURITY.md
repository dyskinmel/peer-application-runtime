# Security policy — source-only Alpha

This Alpha/developer-preview source candidate does not claim production security certification. The production crypto provider and native key-protection path are not finalized.

## GitHub private vulnerability reporting

GitHub private vulnerability reporting must be enabled for `dyskinmel/peer-application-runtime` before public release. Do not post a sensitive vulnerability directly in a public issue. No email address is published for this Alpha.

Until the intended public repository and its private reporting configuration exist, publication remains blocked rather than inventing an alternate contact route.

## Current security posture

- G0-CRYPTO remains subject to an explicit provider/security decision.
- The checked-in local/reference crypto candidate is not a production-provider certification.
- Native key protection, independent security review, native/device/network qualification, soak, physical recovery qualification, and hosted release security configuration remain outstanding.
- Scanner and public-source boundary tooling are defense-in-depth release preparation, not a security certification or Production Qualification.
